# 🧮 Python CLI Calculator

A simple command-line calculator built in Python that supports basic arithmetic operations, history tracking, and reuse of previous results.

## 🚀 Features

- Supports operations:
  - Addition (`+`)
  - Subtraction (`-`)
  - Multiplication (`*`)
  - Modulus (`%`)
  - Exponentiation (`**`)
- Input validation for numbers (including decimals and negatives)
- Reuse the previous result using `p`
- View calculation history
- Clear history anytime
- Continuous loop until user exits

## 🛠️ How It Works

1. Run the script
2. Choose an operation
3. Enter two numbers
4. View the result
5. Continue or exit

## 📋 Commands

| Command | Description |
|--------|------------|
| `p` | Use previous result as input |
| `h` | Show calculation history |
| `c` | Clear history |
| `q` | Quit the calculator |
